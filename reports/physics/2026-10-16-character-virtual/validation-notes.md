# CharacterVirtual: этап 5, шаг 1, проба руками

**Приёмка не закрыта.** Флаг по умолчанию `0`. Автоматические прогоны остановлены после второго непрошедшего стенда механики; экспериментальная сборка оставлена для ручной пробы. PR не предназначен для включения флага по умолчанию.

Во втором прогоне контроллер действительно работал во всех **867/867** наблюдаемых кадрах, включая **360** кадров с нажатым ходом. Предмет `Item` **2,173 кг** сдвинут по горизонтали на **282,762 см**, кружка `ITFO_BEER` **5,810 кг** — на **287,380 см**, бочка **27,091 кг** — на **80,944 см**. За одинаковое окно **3,7 с** (0,7 с покоя + 3 с хода) это **76,422 / 77,670 / 21,877 см/с**; реальные контакты героя подтверждены для всех трёх. Стол **122,004 кг** сдвинут на **179,098 см**, выход героя за его дальнюю границу не зафиксирован. Динамическая опора прошла лишь **1,810 см** при ходе героя **5,445 см** (относительный дрейф **3,651 см**), поэтому поездка на заметное расстояние не подтверждена. Кинематическая опора прошла **319,961 см**, герой — **295,808 см**, относительный дрейф **28,013 см** при допуске стенда 5 см — **FAIL**. Реальный mover `CEMENTARY_COFFIN_01` прошёл **28,406 см**, герой — **28,213 см**, дрейф **0,332 см**, включая подъём обоих на **23 см**. Причина дрейфа кинематической опоры — контроллер или столкновение с окружением таверны — пока не разделена.

Первый прогон ON не включал контроллер: `cv_active=0` при флаге `1`. Причина — `hasCollision()` проверяет пересечение, а не разрешение столкновений. Исправлено на отдельный `isEnabled()`. Дополнительно исправлена старая очистка спящих Item-тел: активный контроллер включает ближайшие мировые Item и сохраняет их тела во сне в радиусе 300 см. Повтор после этих исправлений дал числа выше; дальнейшие исправления механики и прогоны не выполнялись по условию остановки.

## Как попробовать

Локальная macOS-сборка: `OpenGothic/build/opengothic/Gothic2Notr`. В `.bench/character-virtual/manual/` подготовлены копия исходного сейва и `Gothic.ini` с `character_virtual=0`. Из корня этого worktree:

```sh
cd .bench/character-virtual/manual
../../../OpenGothic/build/opengothic/Gothic2Notr \
  -g "/Volumes/DevSSD/Dev/games/Gothic II" -window -devmode -save 1
```

В F2-консоли Marvin: `toggle character_virtual`. Сообщение показывает ON/OFF; переключать можно на ходу. Для включения перед запуском — `[GAME] character_virtual=1`, для исходного движения — `0`. Прыжки, падение, лазание, плавание и ныряние остаются на прежнем пути; NPC остаются на старом движении.
