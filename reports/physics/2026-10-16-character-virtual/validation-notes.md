# CharacterVirtual: этап 5, шаг 1, проба руками

Герой ходит на `CharacterVirtual` под флагом, по умолчанию **0**. Итоговая сборка прошла восемь маршрутов ON; OFF прошёл шесть, застряв на обеих лестницах. Застревания >1 с: **0 ON / 2 OFF**, новых падений с края в ON — **0**. Ограничение усилия уменьшило смещение стола 122 кг с **179,10 до 11,80 см** за 3 с удержания хода; кружка прошла **287,32 см**, бочка — **78,17 см**. p95 физики OFF/ON **0,3575 / 0,3723 мс**, прибавка **0,0148 мс** при лимите 0,3 мс; средний FPS **79,35 / 78,42**, снижение **1,17%** при лимите 5%. Реальный mover перевёз героя с дрейфом **0,332 см** и принят по решению пользователя. Включение по умолчанию ожидает ручной пробы.

## Толчок и опоры

Единственная новая правка механики — дозирование усилия. Общий бюджет импульса за один `move`: `min(mHero × g, 450 Н) × dt`. Все контакты, повторные проверки ступеней и все тела делят этот бюджет. На одно тело дополнительно приходится доля `mHero / (mHero + mBody)`; это непрерывная модель усилия при обычной ходьбе без упора, одинаковая для Item и vob. Импульс прикладывается в точку контакта с учётом инерции. Вертикальный вес `mHero × g` на опоре остаётся прежним. Один только native `mMaxStrength=450` дал столу 184,50 см: Jolt ограничивает отдельный контакт, а сопротивление пола для такого стола ниже 450 Н. Поэтому итог использует общий бюджет и долю по массе.

Одинаковые 0,7 с покоя и **3,0 с удержания хода**; смещение по горизонтали от исходной позиции тела. Последний стол не пропущен насквозь (`passed_through=false`), реальный контакт героя подтверждён у всех четырёх предметов. «После» — итоговая сборка.

## Как попробовать

Локальная macOS-сборка: `OpenGothic/build/opengothic/Gothic2Notr`. В `.bench/character-virtual/manual/` лежат копия исходного сейва и `Gothic.ini` с `character_virtual=0`. Дождаться свободной игры (`pgrep -fl Gothic2Notr`), затем из корня worktree:

```sh
cd .bench/character-virtual/manual
../../../OpenGothic/build/opengothic/Gothic2Notr \
  -g "/Volumes/DevSSD/Dev/games/Gothic II" -window -devmode -save 1
```

F2 → `toggle character_virtual`: сообщение показывает ON/OFF, переключать можно на ходу. Перед запуском — `[GAME] character_virtual=1`; исходное движение — `0`. Прыжок, падение, лазание, плавание и ныряние идут прежним путём. NPC, поиск пути и распорядки не меняются.

Телепортироваться в начало через F2, затем идти к цели. Yaw дан как ориентир направления. Лестницы — земляные ступени `NW_CITY_TO_FOREST_STAIRS01`, участок с общим перепадом 45,875 см.
