# Настил портовых кранов

Шаг М2 [плана проработки мира](../../../../docs/world-detail-plan.md#план-выполнения), пункт «кромки деревянных причалов», 2026-10-30. Лист замысла — [intent.md](intent.md), исполнение — [concept.md](concept.md). Не включено: ждёт приёмки и ворот пользователя по кварталу.

![Оригинал | наше: кран C с набережной, угол настила вблизи](vs-original.jpg)

## Почему краны

Деревянных причалов в порту нет: набережная и пирс к кораблю каменные. `HARBOUR_WOOD_IRON_01` («доски с железом») лежит в порту на четырёх деревянных кранах; самая заметная его часть — дощатый настил крана. Его кромку и накладки и сделали. Замена «причалов» на настилы кранов вынесена ведущей сессии вопросом.

## Что сделано

[`crane_deck.py`](../../../../scripts/content/world/crane_deck.py) — правка М1 на кусках четырёх кранов:
- доски выходят на 3 см за бок плиты, толщина 8 см, под ними тень; на торцах доски расходятся на 1,2 см по нарисованным швам; углы закрыты клином;
- четыре нарисованные накладки поднялись на 2 см над досками и загибаются через кромку.

Настилы A и B лежат через границу кусков: правка читает их из соседних кусков базы через новое `ctx.base_chunks` инструмента М1.

Набор — `harbour-volume-1`: части `working-8` и `cranedeck-1`.
